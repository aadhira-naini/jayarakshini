# Photos for the Birthday Website 🌙

Place your photos in this folder with these exact names:
- **photo1.jpg** — Used in Memory Gallery (slot 1) and Final Surprise
- **photo2.jpg** — Memory Gallery slot 2
- **photo3.jpg** — Memory Gallery slot 3
- **photo4.jpg** — Memory Gallery slot 4
- **photo5.jpg** — Memory Gallery slot 5 and Final Surprise
- **photo6.jpg** — Memory Gallery slot 6

## Tips
- If a photo is missing, the website shows an emoji placeholder — no errors!
- Any image format works: .jpg, .png, .webp (just update the extension in the code)
- For best results, use square or portrait photos

## Music 🎵
Place your birthday song as:
- **birthday.mp3** (in this /public/ folder, not /photos/)

The music starts automatically when she clicks "Open Your Surprise" 🎁
